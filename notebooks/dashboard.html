Key finding: Value-based anomaly detection substantially outperforms timing-based detection in ICU settings. Sepsis patients' measurement sequences are denser and more regular — clinicians respond to deterioration by increasing monitoring frequency, making timing patterns counterintuitively normal. This contrasts with industrial IoT settings where event timing is the primary anomaly signal.

Dataset — ICU Stay Distribution
Median ICU stay: 39h (Hospital A), 38h (Hospital B). Max sequence length set to 72h (covers ~97% of patients). Late-onset cases captured via sliding window strategy.
Neural TPP (SAHP) — Timing-Based Detection
SAHP trained on measurement timing patterns only. AUC-ROC ~0.58 — marginally above random. Sepsis patients receive higher log-likelihood because increased monitoring frequency creates denser, more regular event sequences. This finding highlights a fundamental domain difference from industrial IoT settings.
