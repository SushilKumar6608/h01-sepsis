Personal project applying unsupervised anomaly detection to ICU patient event sequences from the MIMIC-III dataset. Combines an LSTM Autoencoder (reconstruction-based scoring, AUC-ROC 0.926) with a Neural Temporal Point Process (timing-based, currently being added). The two models are designed to catch different types of anomalous signal — value patterns vs. irregular event timing. Includes preprocessing, training, evaluation, and SHAP explainability. README covers setup and results.
